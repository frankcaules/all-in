# ALL IN

A 15-minute interactive noir short film for JIPP Presentation 1, by Frank, Gem and Nathon.
Does an attractive stranger make men take bigger risks? Two studies, one twist.

**Watch it:** https://frankcaules.github.io/all-in/

- **Right arrow** or **Space**: next beat. **Left arrow**: back. **Home**: back to the start.
- **A** / **B**: pick the branch the room voted for (scenes 6 and 15).
- **F**: full screen. **T**: show the timer.

**Presenting in class?** Use https://frankcaules.github.io/all-in/present.html. It is the exact show-day file: it opens
on the black start screen (click once, press F, then T), and the timer starts on the first arrow.

The whole show is one self-contained HTML file. It makes no network requests after it loads, and it works offline
if you save it.

Sources: Ronay & von Hippel (2010); Liu, Wang, Zhu, Zhang & Xing (2022); Shanks et al. (2015); Shanks & Vadillo (2019).
The full references are in the end credits.
